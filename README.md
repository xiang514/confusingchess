# Confusing Chess

一个带魔改规则的线上中国象棋双人对弈网页。

## 当前功能

- 使用自定义登录名和密码注册、登录；棋局昵称直接使用登录名。
- 注册成功后需要再登录；登录后不会自动进入默认房间，需要输入房间名并点击“进入”。
- 先进入房间的玩家执红，第二位执黑。
- 玩家点击“退出”后，另一方页面会同步显示该座位“已退出”。
- 联机房间内点击“重新开始”会开始新局，并交换双方红黑执方。
- 棋局通过 Supabase 同步，可部署到 Vercel。

## Supabase 账号设置

- 建议在 Supabase 的 Authentication 设置里关闭邮箱确认，否则“登录名 + 密码”的新账号注册后仍会处于等待确认状态。
- 如需清空旧账号和所有房间，在 Supabase SQL Editor 运行 `reset-supabase-data.sql`。

## 魔改规则

- 红方先行，双方轮流；被将军时不强制解困。将/帅或驭将/驭帅被吃即负；主动造成将帅碰面即负。
- 每方每局可悔棋 3 次，只能悔自己刚走完且对方未走的一手。联机房间内点“重新开始”后，双方交换红黑执方。
- 马不可过河；驭将/驭帅也按马走且不可过河。象/相可过河：己方半场走田，河对面潜伏为上下左右一格且可后退；潜伏吃子后“功成身退”，随机回己方半场非将军营帐空位。
- 被将军时，若己方马一步能到将/帅位置，可触发翻身上马并合体为驭将/驭帅。
- 每方每局可使用一次东风炮：按车直线吃子，不能空走，吃后炮报废。东风炮未使用时，己方炮与对方将帅同线无遮挡也算将军威胁。
- 走子前可点“将军！”声明；声明错误，或实际造成将军却未声明，随机移除己方一枚棋子，含将/帅与驭将/驭帅。
- 马走到己方兵/卒格时合成骑兵；骑兵可走日，也可上下左右一格；合成后即可后退，也可过河。
- 只有骑兵从河对面退回己方半场时触发惩罚：兵/卒死亡，马随机回己方半场非将军营帐空位。
- 骑兵在河对面被吃时，兵/卒死亡，吃子的棋子正常落在骑兵原格，马被对手缴获并随机出现在对手己方半场非将军营帐空位。骑兵未过河被吃时，兵/卒死亡，马随机回己方半场非将军营帐空位。
- 每局每方随机一个兵/卒为扁平足，不能连续行动两次；刚行动过的扁平足暂不构成将军威胁，直到本方改走其他棋子后恢复；合成骑兵后解除限制。

## 本地预览

```bash
node server.js
```

然后打开：

```text
http://127.0.0.1:3000
```

本地服务只负责预览网页。线上联机数据使用 Supabase。
