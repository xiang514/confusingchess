# Confusing Chess

一个带魔改规则的线上中国象棋双人对弈网页。

## 当前功能

- 使用自定义登录名和密码注册、登录；棋局昵称直接使用登录名。
- 输入同一个房间名即可进入同一局。
- 先进入房间的玩家执红，第二位执黑。
- 棋局通过 Supabase 同步，可部署到 Vercel。

## Supabase 账号设置

- 建议在 Supabase 的 Authentication 设置里关闭邮箱确认，否则“登录名 + 密码”的新账号注册后仍会处于等待确认状态。
- 如需清空旧账号和所有房间，在 Supabase SQL Editor 运行 `reset-supabase-data.sql`。

## 魔改规则

- 马不可过楚河汉界。象/相可以过河，只有停在河对面时进入潜伏模式，只能上下左右移动一格，可以后退；回到己方半场后恢复田字格。
- 每方每局可使用一次东风炮。东风炮按车的方式直线吃子，不能空走，吃完目标后该炮报废。
- 马走到己方兵/卒所在格时，二者合成骑兵。骑兵可走日，也可上下左右单格前进或横走，不可后退，可过河。
- 骑兵在河对面被对方吃时，兵/卒死亡，吃子的棋子正常落在骑兵原格，马被对手缴获并随机出现在对手己方半场的一个空位。
- 骑兵未过河时被对方吃，兵/卒死亡，马逃回该马在对局开始时的初始位置；如果初始位置被占，则按普通吃子处理。
- 每方五个兵/卒中随机一个是扁平足，不能连续两次作为本方行动棋子；合成骑兵后解除限制。
- 被将军时，如果本方马能一步走到将帅所在位置，可以触发翻身上马。触发后将帅移动到马的位置并变为驭将或驭帅，之后按马的方式走棋，且仍不可过河。
- 仅在自己刚下完一步、对方还未下时可以悔自己的上一手；每方每局最多悔棋 3 次。
- 主动造成将帅碰面的一方判负。

## 本地预览

```bash
node server.js
```

然后打开：

```text
http://127.0.0.1:3000
```

本地服务只负责预览网页。线上联机数据使用 Supabase。
